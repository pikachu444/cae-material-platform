# 처리·반복 실험 통계를 연결하는 방법

2026-09-07 · 흐름 제안. 첫 화면의 `처리·통계`에서 합성 곡선으로 조작할 수 있다. 생산 알고리즘 승인은 아니다.

**곡선의 모든 점을 한꺼번에 모아 평균 내지 않는다.** 같은 비교 조건의 독립 실험을 같은 비중으로 다룬다.
측정점이 많은 시험에 더 큰 가중치를 주면 장비의 샘플링 속도가 결과를 좌우하게 된다.

## 사용자가 하는 일

1. 조회한 실험에서 비교할 시편/시험을 선택한다. 소재가 같아도 온도·속도·방향·제조 상태·응력/변형률 정의가 다르면 자동으로 같은 그룹으로 묶지 않는다.
2. 원본을 유지한 채 단위·물리량·필요한 처리 상태를 확인한다. crop/zero 보정/평활화 등은 검증된 해당 시험 처리에서 수행하며 숨겨진 자동 정리를 넣지 않는다.
3. 동일한 x축 의미로 비교 가능한 공통 관측 구간을 구한다. 기본 제안은 공통 격자에서 선형 보간, 외삽 없음이다. 원본과 처리된 개별 곡선을 함께 볼 수 있게 한다.
4. 평균과 표본 표준편차, 최소·최대, 기여 실험 수를 확인한다. 조기 파단 이후를 0으로 채우거나 살아남은 시험만으로 만든 평균을 전체 평균처럼 표시하지 않는다.
5. 결과를 명시적으로 저장하고 처리 데이터로 다운로드한다. 모델이 필요하면 저장한 결과에서 모델 생성으로 이어간다. solver 카드 생성·다운로드는 별도 업무다.

기본 화면에는 선택한 실험, 비교 조건, 포함/제외 상태와 이유, 구간, 주요 결과만 둔다.
격자 수/간격, 허용한 정렬 방법, 제외 후보 검토는 고급 설정에서 연다. 기본값은 검증된 시험별 recipe가 있는 경우에만 제공한다.
검증된 recipe가 없으면 필요한 입력을 묻고, 검증된 것처럼 자동값을 채우지 않는다.

## 원본·연결·저장

원본 파일은 각 실험의 별도 자료로 유지한다. 통계 결과에는 사용한 실험 ID, 실제 데이터/설정과 산출값을 저장한다.
이것은 결과를 이해하고 다시 확인하기 위한 자료이며 모든 편집의 리비전 이력이 아니다.
이름 변경은 링크를 유지한다. 입력 실험이나 계산 설정을 바꿨다면 화면의 현재 계산 결과 여부만 다시 판정한다.
이전 저장 결과 자체를 바꾸거나 삭제하지 않는다.

## 기존 자산과 이 시안의 차이

| 자산 | 재사용할 부분 | 연결 전에 확인할 부분 |
| --- | --- | --- |
| [common_ensemble.py](../../../backend/src/cmp/modules/processing/domain/common_ensemble.py) | 공통 구간 정렬, 선형 보간, 반복 통계 | 정규근사 구간과 작은 표본 수에서의 의미, 출력 schema/API/저장 연결 |
| [reference_tensile_replicates.py](../../../backend/src/cmp/modules/statistics/domain/reference_tensile_replicates.py) | 같은 격자의 인장 반복 통계, 최소·최대, 평균 구간 | 정렬 전 단계, Student-t 가정, 실제 데이터와 허용오차 |
| 이번 workspace.js | 계산 전/후·저장 전/후·입력 변경의 화면, 예시 CSV | 브라우저 계산이며 운영에 재사용하지 않는다. API·권한·영구 저장과 수치 qualification 없음. |

시안은 합성 단조 인장 3회, 공통 구간 0–12%, 151점으로 보여준다. 평균·band와 CSV는 같은 예시 결과를 사용한다.
12%를 넘어 관측된 다른 개별 곡선은 남겨서 먼저 끝난 시험이 있다는 것을 볼 수 있다.
결과 저장은 해당 브라우저 탭의 sessionStorage까지만 확인한다. 서버에 저장되었다는 의미가 아니다.

## 함께 저장하면 유용한 지표

곡선 통계 외에 항복강도, 최대응력, 파단 변형률 등 시험별 scalar의 개별값·평균·산포·최소·최대를 별도로 제공하는 것을 제안한다.
항복 정의와 파단 판단은 시험별 기준이 필요하다. 특히 일찍 파단한 시험을 공통 구간 밖이라는 이유로 숨기지 않는다.
사용자가 말한 “취약한 범위”는 먼저 관측 최소·최대와 파단 분포로 보여주고, 설계 허용 하한은 별도의 표본 수·분포·신뢰수준 검토 후 제공한다.
관측 최소값, 평균의 신뢰구간, 모집단을 포함하는 tolerance interval은 같은 의미가 아니다.
[NIST 구간 해석](https://www.itl.nist.gov/div898/handbook/prc/section2/prc263.htm).

## 구현 전에 끝낼 검증

선형/상수 기준 곡선, 서로 다른 샘플 수, 격자 불일치, 교집합 없음, 중복·비단조 x, NaN, 단위 혼합,
조기 파단, 조건 불일치, 작은 표본 수를 검사한다. 원본 bytes와 ID/link 유지, 저장 후 재조회 및 실제 처리 CSV를 대조한다.
허용오차는 축 단위·보간 오차·수치 정밀도를 고려해 기준 데이터와 함께 승인한다. 이 시안의 숫자를 생산 정답으로 삼지 않는다.
