## 5. 종합

- 골격(카탈로그·리비전·리뷰·계보·권한 3중 enforcement)은 사내 요구와 방향이 정확히 일치하고 품질이 높다. GRANTA 구조 이식은 구조적으로 가능하다.
- 사내 도입의 실질 블로커는 기능 전반이 아니라 주변부다: 스키마 번들 import(G1-G4), 로그인(G9), 업로드 승인(G11), 역할 preset(G12), audit 배선(G13).
- 도메인 기능 갭은 통계(G19)와 Export 템플릿/솔버/단위계(G20-G21) 두 덩어리가 크다. 프로세싱·피팅은 이미 사내 파이프라인과 대등하거나 우수하다.
- 배포는 Hyper-V Ubuntu VM + Docker Engine(#162)으로 라이선스·보안 문제 없이 해결 가능하며 Windows 네이티브가 보조 경로다.
