# 기존 frontend 작업 지침

[공통 지침](../../docs/repository/frontend-development.md)을 따른다. 이 앱은 새 기반 검증과 일괄 전환 전까지 보존할 기존 구현이다.

- 기존 hotspot의 책임을 옮기면 호출자·단위·계산·검증·상태·복구 동작을 먼저 확인한다. 기존 검사와 연결해 이동한다.
- 모든 변경에 function → controller → UI 순서를 강제하지 않는다. 실제 책임이 나뉠 때만 분리한다.
- 새 기능을 큰 기존 파일에 더 쌓기보다 승인된 개편 단위의 소유권을 따른다. 줄 수만으로 helper나 wrapper를 만들지 않는다.
- 기존 전역 CSS에 새 기능 선택자를 추가하지 않는다. 기존 primitive의 API는 그 소비자를 수정할 때 확인하며 새 앱의 필수 component로 복제하지 않는다.
- 루트 `npm run check`는 이 앱의 guard·build·test다. 새 앱 검사 결과와 혼동하지 않는다.
- 삭제는 대체 업무·남은 사용처·전환과 복구 검증 뒤 수행한다. 현재 DOM·화면 순서의 영구 호환은 개편 조건이 아니다.
